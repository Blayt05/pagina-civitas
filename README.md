# CIVITAS

Página web de CIVITAS, un grupo estudiantil cristiano. Actualmente muestra una página de "en construcción".

Sitio: <https://civitastec.com>

Hecho con [Next.js](https://nextjs.org) (App Router), TypeScript y Tailwind CSS.

## Instalación

```bash
npm install
```

## Desarrollo local

```bash
npm run dev
```

Después abre <http://localhost:3000> en el navegador.

## Otros comandos

```bash
npm run build   # Genera la versión de producción
npm run lint    # Revisa el código con ESLint
```

## Despliegue

El sitio se despliega en [Vercel](https://vercel.com).
